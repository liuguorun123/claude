# 日程管理功能

## 功能说明

当你在飞书中告诉助理Z今天的安排时，机器人会：

1. **自动识别**：检测消息中是否包含日程信息
2. **智能提取**：使用 AI 提取日期、时间、事件、地点等信息
3. **自动存储**：保存到日报文件 `日报/{日期}/日程安排.md`
4. **确认回复**：返回确认消息，告诉你已记录

## 使用示例

### 直接说出安排

```
用户: 今天上午10点有早会
助理: ✅ 日程已记录！

📅 日期：2026-05-12
📋 摘要：今天上午10点有早会

详细安排：
• 上午10点 - 早会

已保存到日报文件，可随时查看。
```

### 多个安排

```
用户: 下午2点和客户开会，地点在会议室A，4点项目总结
助理: ✅ 日程已记录！

📅 日期：2026-05-12
📋 摘要：下午2点客户会议，4点项目总结

详细安排：
• 下午2点 - 和客户开会（📍会议室A）
• 下午4点 - 项目总结

已保存到日报文件，可随时查看。
```

### 设置提醒

```
用户: 提醒我3点提交报告
助理: ✅ 日程已记录！

📅 日期：2026-05-12
📋 摘要：下午3点提交报告

详细安排：
• 下午3点 - 提交报告

已保存到日报文件，可随时查看。
```

## 识别关键词

机器人会自动识别以下关键词：

- **时间词**：今天、明天、上午、下午、早上、晚上、点、点半
- **事件词**：安排、计划、日程、会议、开会、提醒

## 存储位置

日程信息会保存到：

```
/data/日报/
└── 2026-05-12/
    └── 日程安排.md
```

## 查看日程

### 在飞书中查看

```
用户: 今天有什么安排？
助理: （会读取并展示今天的日程安排）
```

### 直接查看文件

在 Replit Shell 中：
```bash
cat 日报/2026-05-12/日程安排.md
```

## 技术实现

### 文件结构

```
飞书机器人/
├── schedule_handler.py  # 日程处理模块
├── ws_client_v4.py      # 主程序（已集成）
├── storage.py           # 存储管理
└── example_schedule.py  # 使用示例
```

### 处理流程

```
用户消息
    ↓
is_schedule_message()  →  否  →  正常 Claude 回复
    ↓ 是
extract_schedule()  →  提取日程信息
    ↓
save_schedule()  →  保存到文件
    ↓
format_schedule_response()  →  返回确认消息
```

## 注意事项

1. **只记录明确的日程**：机器人不会编造内容，只记录你明确说出的安排
2. **支持追加**：多次说出安排会追加到同一个文件
3. **智能识别**：即使没有说"安排"，只要有时间和事件也会识别

## 常见问题

**Q: 为什么我的消息没有被识别为日程？**
A: 请确保消息中包含时间和事件信息，例如"10点开会"或"下午有会议"。

**Q: 可以修改已记录的日程吗？**
A: 目前不支持修改，只能追加。如需修改，请手动编辑文件。

**Q: 支持提醒功能吗？**
A: 目前只支持记录，不支持定时提醒。如需提醒，可以使用飞书自带的日历提醒。
