# 天气API配置说明

## 获取和风天气API Key

### 第一步：注册账号

1. 访问 [和风天气开发平台](https://dev.qweather.com/)
2. 点击「注册」创建账号
3. 完成邮箱验证

### 第二步：创建项目

1. 登录后，进入「控制台」
2. 点击「创建项目」
3. 填写项目名称（如"AI办公助理"）
4. 选择「Web API」
5. 创建完成后，获得 **API Key**

### 第三步：订阅免费版

1. 在项目详情页，选择「订阅」
2. 选择「免费版」（每天1000次调用，足够使用）
3. 确认订阅

### 第四步：配置API Key

将获得的API Key填入 `.mcp.json` 文件：

```json
{
  "mcpServers": {
    "weather": {
      "command": "python",
      "args": ["工具/weather-mcp.py"],
      "env": {
        "WEATHER_API_KEY": "你的API_KEY"
      }
    }
  }
}
```

## API限制

| 版本 | 每日调用次数 | 价格 |
|------|-------------|------|
| 免费版 | 1,000次 | 免费 |
| 基础版 | 10,000次 | ¥99/月 |
| 高级版 | 100,000次 | ¥499/月 |

**免费版完全够用**，每天1000次调用可以满足需求。

## 支持的城市

和风天气支持全球城市，成都的城市ID已配置为 `101270101`。

如需查询其他城市，可以访问 [城市列表](https://dev.qweather.com/docs/api/geoapi/city-lookup/)

## 测试配置

配置完成后，重启Claude Code，然后说：
"今天成都天气怎么样"

如果返回天气信息，说明配置成功。
